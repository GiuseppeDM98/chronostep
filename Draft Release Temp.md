## ✨ New Features
- Added a monthly report page with per-task totals and note highlights.
- Added month and year filters to focus the report on a specific period.
- Added a Report link in the top navigation for quicker access.
- Added modal editing for tasks, steps, and work logs in the task detail view.
- Added the ability to reassign a substep to a different parent step.

## 🔧 Improvements
- Added warnings when pressing Esc with unsaved changes in modals.
- Improved task and step descriptions to respect line breaks.
