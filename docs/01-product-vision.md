# Product Vision

## Overview
This application is a lightweight personal task‑tracking web app built with Next.js. It focuses on hierarchical task management (tasks → steps → substeps) and timestamped work logs to capture what was done and when.

## Goals
- Provide a simple but powerful structure for breaking down work.
- Allow fast logging of daily activity.
- Offer clear visibility of progress over time.
- Remain portable, local-first, and easy to extend.

## Key Use Cases
1. Create and manage tasks with metadata (priority, tags, due date).
2. Break tasks into steps and recursively into substeps.
3. Record actions, notes, and timestamps via work logs.
4. Review task‑level and global timelines.
5. Filter tasks by state, tags, and priority.

## MVP Scope
- Basic CRUD for Tasks, Steps, WorkLogs.
- LocalStorage persistence.
- Minimal UI with Tailwind.
- Task list, task detail, timeline views.

## Future Enhancements
- Database-backed sync.
- Analytics on productivity and time allocation.
- Calendar export.
- Focus / Pomodoro mode.
- Multi-device access.
